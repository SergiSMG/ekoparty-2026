# Public assets

Place the **reviewed, public-only** presentation in this directory with this exact
filename (case-sensitive on GitHub Pages):

`Ekoparty_2026_From_One_Identity_to_Full_Compromise.pdf`

The Download slides link already points to this file. Until you add it, the
download will return a 404. The source presentation has deliberately not been
copied into this folder: review and export your public deck yourself.

Do not publish speaker notes, hidden slides, internal URLs, private customer
information, or screenshots that are not cleared for publication.

## Optional assets

- Speaker photos: place approved photos here, for example `sergio.webp`,
  `victor.webp`, and `lucas.webp`. They are not used by the current design.
  If you add them to the page, use descriptive alt text, explicit image
  dimensions, optimized files, and lazy loading for below-the-fold images.
- Favicon: place an approved icon here, for example `favicon.svg`, and add
  `<link rel="icon" href="assets/favicon.svg" type="image/svg+xml">` to the
  `<head>` of `index.html`.
- Other images: use small, optimized, publication-approved files. Reference
  them with relative `assets/...` paths.

No photos, Microsoft logos, external fonts, or decorative screenshots are
required. The page's visual treatments are CSS and an inline decorative SVG.
